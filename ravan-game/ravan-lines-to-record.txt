RAVAN'S LINES TO RECORD
Record each line in a big, booming Ramlila voice and save it with the file name shown.
The player's name is left out on purpose: the game shows the name on screen.
Then in the game: Settings > Edit Ravan's lines > Import many recordings, and pick all the files at once.
You do not need every line. Any line without a recording uses the computer voice or a subtitle.
